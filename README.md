# tech-radar-test

Interactive technology radar visualisation built with D3.js, based on [Zalando's Tech Radar](https://github.com/zalando/tech-radar).

Technologies are plotted across four quadrants (Languages & Frameworks, Infrastructure & Platforms, Datastores, Tools) and four rings (Use, Trial, Assess, Hold).

## Usage

Serve the files with any static web server, or open `index.html` directly. Edit `config.json` to add, remove, or recategorise technologies.

## Dependencies

D3.js v7 (loaded from CDN). No build step required.
